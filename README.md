# 🏠 House Price Prediction using ANN + Flask
A machine learning web application that predicts house prices based on user input features using an Artificial Neural Network (ANN) built with Keras and deployed using Flask.

# 📌 Project Overview
This project uses a trained Artificial Neural Network model to predict house prices based on various features such as:
1. Location (longitude, latitude)
2. House age
3. Number of rooms
4. Total bedrooms
5. Population
6. Households
7. Median income
8. Ocean proximity

A Flask web app is built to take user inputs and display predicted results in real time.

# 🧠 Machine Learning Model
- Model Type: Artificial Neural Network (ANN)
- Framework: TensorFlow / Keras
- Problem Type: Regression
- Loss Function: Mean Squared Error (MSE)
